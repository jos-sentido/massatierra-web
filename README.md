# massatierra-web

Sitio web oficial de **Massatierra** — tierras físicas, pararrayos y protección contra
sobretensiones. Zapopan, Jalisco.

Repo **aislado**: aquí vive solo el sitio, porque es entregable del cliente y tiene su
propio ciclo de vida. El trabajo interno de agencia (propuestas, reportes, pauta) vive
en otros repos.

- **Stack:** Next.js + Tailwind + Firebase
- **Contexto del proyecto:** [`contexto/`](contexto/) ← empezar por ahí
- **Expediente del cliente:** `sentido-core/clientes/massatierra/`
- **Build en Asana:** [Massatierra - Pagina Web](https://app.asana.com/1/1113680433356414/project/1220816335362266/task/1220821460903737)
